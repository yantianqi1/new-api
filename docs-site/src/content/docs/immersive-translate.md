---
title: Immersive Translate
---

Immersive Translate 是一款广受好评的双语网页翻译浏览器扩展。依托 waner~ API站 的模型能力，它的翻译效果远超普通机器翻译。

### 第 1 步：安装扩展

从官方网站安装： https://Immersive Translate.com

### 第 2 步：配置自定义 API

点击扩展图标 → 设置 → 翻译服务

打开 OpenAI（或「自定义 AI 翻译服务」）

### 填写以下内容

APIKEY：sk-your-api-key

模型：选择「自定义」并输入模型名称（建议使用轻量快速的模型，例如 gpt-4o-mini）

自定义 API 接口地址： https://api.aiwanai.cc/v1/chat/completions

### 第 3 步：调整并发与成本

整页翻译会发出大量小请求，因此建议：

每秒最大请求数：降到 5–10，避免触发速率限制（429）

每次请求的最大段落数：调高可减少请求次数和成本

选择价格便宜的模型——翻译任务不需要旗舰模型（价格详见 Pricing 页面）

### 第 4 步：验证

打开任意外文页面，点击扩展图标启用翻译。出现译文即表示成功；详细信息可在 Usage Logs 中查看。

### 故障排查

401：APIKEY 是否完整（以 `sk-` 开头）？

频繁 429：调低每秒最大请求数，或查看错误码与故障排查文档。

译文为空：更换模型尝试；少数模型对翻译提示词处理不佳。
