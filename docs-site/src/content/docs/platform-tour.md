除了中转 API 调用之外，waner~ API站 控制台还提供一整套覆盖集成、消费、可观测性与安全的工具箱。

这是一份按场景组织的导览——部分功能按站点开启，如果某个入口不存在，以站点的实际配置为准。

### 集成与调试

- **Playground**（侧边栏 Chat → Text Chat）：选择模型与分组后直接在站内对话——无需安装任何东西即可验证令牌与连通性；只有你明确启用的参数才会随请求发送。
- **Image Generation**（Chat → Image Generation）：输入提示词即可生成图片，支持瀑布流画廊、灯箱预览与一键下载；历史记录保存在浏览器本地。API 用法详见图像生成指南。
- **文档中心**（顶栏 Docs）：内置双语集成指南；登录后选择一把密钥，每个代码示例都会自动改写成你的真实 base URL 与密钥——复制即可运行；也可以就当前页面向 AI 提问。
- **CC Switch 一键导入**（API Keys → 行操作）：一键把站点地址、密钥与模型映射推送到本地 CC Switch，覆盖 Claude Code、Codex CLI 等工具——详见 CC Switch 指南。
- **第三方应用**（Chat → Third-party / 密钥行操作）：打开站点精选的第三方客户端（网页聊天界面、Immersive Translate 等）并自动附带你的密钥——无需手动复制粘贴配置。
- **密钥高级选项**（API Keys）：批量创建、过期时间预设、配额上限、模型允许名单，以及 IP 允许名单（支持 CIDR），让每把密钥只拥有所需的最小权限。

### 余额与福利

- **钱包**（Personal → 钱包）：余额、在线充值（多种支付方式）、兑换码与账单记录（可按订单号搜索），全部集中在一个页面。
- **订阅计划**（钱包内，开启时显示）：周期性模型配额包；可在订阅优先 / 钱包优先 / 仅订阅 / 仅钱包之间自选扣费顺序。
- **赠送额度批次**（钱包内）：永久余额与有过期时间的额度分开统计，每个批次都标注来源（充值赠送、邀请奖励、签到奖励等）与过期日期。
- **每日签到**（Personal，开启时显示）：日历式签到，随机额度奖励。
- **活动 / 试用码**（钱包内，开启时显示）：输入兑换码可临时解锁隐藏分组（如高级模型池），直到其过期；符合条件的充值可能会自动发放个人试用码。
- **邀请奖励**（钱包内，开启时显示）：生成你的邀请链接；奖励可转入可用的账户额度。

### 用量与可观测性

- **Usage Logs**（General → Usage Logs）：普通、绘图与异步任务日志分标签页展示；绘图日志可内联预览生成的图片；日志详情可展示完整请求内容；顶部有实时的消费 / RPM / TPM 统计。
- **性能看板**（General → Performance）：基于真实流量计算的各分组健康度与延迟（24h / 7d），可展开到单模型明细——选择分组前不妨先看一眼。
- **模型市场**（顶栏 Models）：每个模型的上下文窗口、能力标签、可用分组、各分组价格（含阶梯计价明细），以及实测延迟与成功率。
- **排行榜**（顶栏 Hot）：基于用量的模型榜单、厂商市场份额，以及上升 / 下降的趋势变动。
- **总览看板**（General → Overview）：公告、常见问题、上游供应商状态、可用性监控，以及 API endpoint 卡片——可配合本地测速一起使用。
- **通知中心**（顶栏铃铛）：系统通知与公告两个标签页，并带有未读角标。

### 账号与安全

- **Passkey 登录**（Personal）：使用指纹 / 面容 / 安全密钥登录，无需输入密码。
- **双因素认证**（Personal）：TOTP 验证码加备用恢复码。
- **登录会话管理**（Personal）：查看所有活跃设备与登录方式；可吊销单个设备或登出其他全部设备。
- **通知渠道**（Personal → Notifications）：余额不足提醒等可通过邮件 / webhook / Bark / Gotify 发送，支持专门的通知地址与阈值。
- **账号绑定**（Personal）：绑定或解绑邮箱、微信、Telegram，以及 GitHub 等 OAuth 提供商。
- **侧边栏定制**（Personal）：隐藏你从不使用的菜单项，保持控制台清爽。

### 出问题时

先查阅 Error codes & troubleshooting，按错误码与排障指南自主排查。
