---
title: 分组
---

令牌的分组决定了请求由哪一组上游渠道服务，以及适用的价格倍率。

### 什么是分组

每个分组都对应一组上游渠道和一个价格倍率。想对比某模型在各分组下的价格，请在 Pricing 页面打开它的详情。

在控制台 → API Keys 中创建或编辑令牌时可以选择其分组，共有两种模式：

| 模式 | 含义 |
| --- | --- |
| 跟随账户分组（默认） | 令牌没有自己的分组，始终跟随账户当前分组 |
| 指定分组 | 锁定到该分组；若其不可用，请求会失败 |
