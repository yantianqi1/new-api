---
title: Endpoint 与本地测速
---

waner~ API站 通常提供多个接入点（不同的 API 域名），同一个 key 在所有接入点上通用。控制台 → Overview 的「API Info」卡片列出了全部接入点，而本地测速能帮你从自己的网络环境中找出最快、最稳定的那一个。

### 为什么要在你自己的机器上测速

接入点的性能取决于你所在的位置——地区、运营商、代理配置——因此在站点服务器上测出的结果毫无参考价值。直接从浏览器里测速也不可靠：扩展程序和代理规则常常会干扰测得的数值。

所以测速是在你的电脑上进行的：页面生成一份 PowerShell 脚本，你在本地运行它，然后把结果导回页面。结果只保存在你的浏览器里——不会向服务器上传任何数据。

### 如何使用

打开控制台 → Overview，点击「API Info」卡片角落的 Local speed test。

在对话框中复制脚本（或下载为 .ps1 文件）。你可以展开脚本逐行审查：它只向已配置的接入点发送 GET /api/ping 请求，不下载也不执行任何内容，并且拒绝探测私有/内部地址。

打开 PowerShell，粘贴脚本并按回车。Windows 自带的 PowerShell（5.1+）就够用；macOS / Linux 需先安装 PowerShell 7（如果结果无法自动写入剪贴板，就从终端输出中手动复制）。

运行结束后，结果会复制到你的剪贴板。回到页面，点击 Import result from clipboard，或手动粘贴。

### 读取结果

每个接入点会探测 3 次，超时时间为 6 秒，延迟取成功探测的中位数。导入后，列表会按 可靠性 → 成功率 → 延迟 重新排序，顶部的横幅会直接给出推荐的接入点。

| 徽标 | 含义 |
| --- | --- |
| 绿色 3/3 · 128ms | 3 次探测全部通过——稳定 |
| 黄色 1/3 · … | 部分通过——间歇性不稳定 |
| 蓝色 "reachable, unverified" | 可连接，但响应并非来自本站网关（可能被中间设备拦截）——谨慎使用 |
| 红色 "connection failed" | 无法访问 |

将鼠标悬停在结果徽标上，可查看延迟范围和具体的失败原因（超时、DNS 解析失败、TLS 握手失败等）。

### 补充说明

结果有效期为 10 分钟，之后自动清除；站点变更接入点列表后结果也会失效——重新运行脚本即可。

测速只衡量网关的连通性和延迟，不包含模型请求——生成速度还取决于上游供应商。

每一行的 external speed test 按钮会打开第三方的多地区测速工具，作为补充参考。

选好接入点后，点击 copy，替换客户端中的 API base URL——key 保持不变。
