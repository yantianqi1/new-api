title: 错误码与排障
---

出问题时，先在 Usage Logs 里找到该请求的完整错误，再对照下表查找。多数问题两分钟内即可自行解决。

### 三步自检

站内验证：打开 Playground，向同一模型发一条消息。如果站内正常，说明网关没问题，问题出在你的客户端配置。

检查三项要素：Base URL（`/v1` 多了还是少了？）、密钥（`sk-` 前缀是否完整？）、模型名称（是否与 Pricing 页面完全一致？）。

查看 Usage Logs：每次失败调用的状态码和错误详情都记录在里面。

### 错误码参考

| 状态码 | 典型错误 | 原因与处理 |
| --- | --- | --- |
| 401 | `invalid_api_key` | 密钥错误、已删除或缺少 `sk-` 前缀；或者 Base URL 指向了其他站点。重新创建密钥，并确认地址为 `https://api.aiwanai.cc` |
| 403 | `Forbidden` | 密钥存在模型/IP 限制，或其所属分组无权访问该模型。检查密钥设置，或创建一个无限制的密钥 |
| 404 | `model_not_found` | 模型名拼写错误、模型不在你的分组内，或路径缺少 `/v1`。去 Pricing 页面复制准确名称 |
| 408 | 请求超时 | 调大客户端超时时间；改用流式输出；或换一个更快的模型 |
| 413 | `context_length_exceeded` | 输入或历史记录超出模型的上下文长度。精简历史记录、降低 `max_tokens`，或改用长上下文模型 |
| 429 | `rate_limit_exceeded` | 触发并发或频率限制。降低并发量，并加入指数退避重试 |
| 429 | `insufficient_quota` | 余额或密钥配额耗尽。在钱包充值，或调高密钥配额 |
| 500/502 | 上游错误 | 站点或上游临时故障——稍后重试；若持续存在请反馈 |
| 503 | `no available channel` | 暂时没有渠道为该模型提供服务。稍后重试，或更换模型/分组；若反复出现，请反馈模型名称和发生时间 |

### 常见案例

Claude Code 无法连接

`ANTHROPIC_BASE_URL` 必须为 `https://api.aiwanai.cc`—— 末 尾 不 要 带 `/v1`

编辑 `settings.json` 后需重启终端

参见 Claude Code 指南

Codex 返回 401 或 404

`base_url` 必须为 `https://api.aiwanai.cc/v1`（ 带 `/v1`），且 `wire_api = "responses"`

密钥放在 `auth.json`，不是 `config.toml`

参见 Codex CLI 指南

### 流式输出中途断开

调大客户端超时时间；curl 加 `-N` 禁用缓冲

自建 Nginx 反向代理需要设置 `proxy_buffering off;`

### 内容被拒绝

你的输入触发了内容审核。请调整措辞；越狱式用法违反站点规则，多次触发可能导致账号受限

### 还是没解决？

重新检查一遍请求参数与错误码对应的说明，确认 Base URL、密钥与分组是否正确

文档页面右下角的 AI 助手支持直接粘贴错误信息（若本站已启用）
